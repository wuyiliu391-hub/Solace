# Solace v17.8.0 Changelog

版本：17.8.0 (Build 291)
日期：2026-08-06

## 角色生命循环

- 每轮用户消息先通过本地规则改变角色持续情绪；AI 的回合状态再以受限权重归并，避免角色状态被一次生成任意覆盖
- 新增角色承诺：识别用户明确提到的近期事项，并在后续对话或合适的主动联系中自然跟进
- 用户反馈事项结果后，承诺会结算为重要、置顶的共同经历记忆
- 用户表达“不想谈”“别问”“需要空间”时，承诺会取消，角色停止追问

## 关系与边界

- 新增按会话持久化的关系上下文：信任感、用户边界、未修复矛盾和最近重要经历
- 道歉、拒绝、冲突、脆弱分享和事项结果会产生不同的关系后果
- 既有 `isInFriction` 状态现在会跟随未修复矛盾同步更新

## 主动行为

- 新增本地确定性主动策略：用户开关、静默时段、冷却、每日上限、近期互动和用户边界均在生成前生效
- 到期承诺可作为主动联系理由；没有合理理由时角色会选择不打扰

## 内置作者角色

- 内置作者人格升级为真实经历的公开化投影，保留核心价值与表达方式，不包含现实姓名、地点或私密经历
- 作者角色资料、别名和互动设置均改为只读；Repository 层同时拒绝覆盖内置角色
- 内置角色会在升级时刷新官方设定，旧用户无需删除后重建

## 数据与测试

- 数据库升级至 v70，新增 `character_commitments` 与 `relationship_contexts` 表
- 新表已接入迁移、缺表恢复、备份、导入、数据清除、会话删除和角色删除
- 新增承诺生命周期、关系边界/修复和主动策略测试
