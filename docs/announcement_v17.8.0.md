# Solace 17.9.0 更新公告

版本：17.9.0 (Build 292)
日期：2026-08-09

## 本次更新重点

### 1. Operit 设备 Agent 全链路强化

- 统一意图识别、工具规划、确定性路由和参数提取。
- 增加电量、通知、进程、应用和工作区等设备能力。
- 工具执行受权限、频控和审计策略保护。
- 失败时返回真实执行结果，不再伪装成功。
- 设备操作完成后继续使用角色口吻反馈，同时保留剧情、关系和人设上下文。

### 2. 角色关系与互动体验

- 角色承诺、共同经历、信任感、用户边界和未修复矛盾继续沉淀到关系上下文。
- 主动互动支持开关、静默时段、冷却、每日上限和空间保护。
- 单聊状态栏显示每轮实时变化的情绪 emoji。
- 点击放大图标可查看完整情绪、强度和当下内心想法。

### 3. 隐藏状态与本地体验

- 隐藏聊天与隐藏联系人现在完全区分。
- 两者分别提供独立恢复入口。
- 隐藏聊天不会隐藏联系人，也不会删除聊天记录。
- 本地数据、角色关系、承诺、主动互动和工具任务流程补充了更多兼容处理和测试。

### 4. 功能收敛与清理

- 清理废弃的虚拟电话路由提示。
- 清理旧 TTS、音色克隆和录音转写遗留链路。
- 移除废弃的 Live2D、音乐陪伴、宠物和故事模块入口及旧实现。
- 减少无效依赖和历史功能对维护与包体的影响。

### 5. 升级提示

- 本版本继续使用本地 SQLite 和 SharedPreferences 保存用户数据。
- 覆盖安装通常会保留应用数据，请勿在系统设置中执行“清除数据”。
- 建议重要用户在更新前先导出应用内备份。

角色在主动发消息前会先遵守本地策略：

- 用户是否开启主动消息
- 静默时段
- 冷却时间与每日上限
- 用户是否刚刚互动
- 用户是否要求空间
- 是否存在需要兑现的承诺

没有合适理由时，角色会选择不打扰。

### 4. 内置作者角色升级

作者角色完成公开化人格升级：保留真实的价值观、表达方式和创作动机，但不公开现实姓名、地点或私密经历。

作者资料和互动设置现已锁定，确保官方角色身份、边界和人格不会被修改。

### 5. 本地数据升级

数据库升级至 v70，新增角色承诺和关系上下文持久化。备份、导入、数据清除及删除流程已同步支持。
