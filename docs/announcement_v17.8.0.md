# Solace v17.8.0 更新公告

版本：17.8.0 (Build 291)
日期：2026-08-06

## 角色开始记得、在意，并留下后果

这次更新不以增加功能入口为目标，而是让角色与用户之间的关系能跨过一轮对话继续存在。

### 1. 角色承诺与共同经历

当你说“明天要考试”“下周答辩”“今晚加班”时，角色会保存这件事。

- 在合适时间，它会自然地关心结果
- 你说“考完了”“没考好”后，结果会成为你们的共同经历
- 你说“不想谈了”后，它会停止追问，不再把关心变成打扰

### 2. 关系有了边界和修复

新增关系上下文，持续记录：

- 信任感
- 用户明确表达的互动边界
- 尚未修复的矛盾
- 最近重要经历

用户的道歉、拒绝、冲突和脆弱分享，会在后续对话中留下不同影响。

### 3. 主动联系不再是定时骚扰

角色在主动发消息前会先遵守本地策略：

- 用户是否开启主动消息
- 静默时段
- 冷却时间与每日上限
- 用户是否刚刚互动
- 用户是否要求空间
- 是否存在需要兑现的承诺

没有合适理由时，角色会选择不打扰。

### 4. 内置作者角色升级

作者角色完成公开化人格升级：保留真实的价值观、表达方式和创作动机，但不公开现实姓名、地点或私密经历。

作者资料和互动设置现已锁定，确保官方角色身份、边界和人格不会被修改。

### 5. 本地数据升级

数据库升级至 v70，新增角色承诺和关系上下文持久化。备份、导入、数据清除及删除流程已同步支持。
