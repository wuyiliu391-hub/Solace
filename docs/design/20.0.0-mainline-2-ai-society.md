# 20.0.0 主线二 · 多角色社会

> 上级文档：[`roadmap-20.0.0.md`](../roadmap-20.0.0.md)
> 迭代：A3（关系表）→ A4（私聊+冲突）→ A5（共同活动+小团体）
> 数据库：v74 → v76
> 前置依赖：主线一（角色需要有"生活"，才有社交的素材）

---

## 1. 设计目标

让 AI 角色之间形成**真正的社会**：

- 角色两两之间有独立关系值，会随时间/互动演化
- 用户可"偷看"两个 AI 的私聊（模拟微信长按查看）
- AI 会吵架、冷战、和好，并主动向用户倾诉
- AI 自发组织共同活动（看电影/打游戏/旅行）
- AI 自然形成小圈子，有排挤、抱团

**核心原则**：所有 AI 间互动**最终都沉淀为记忆**，进入各自 `MemoryEngine`，让"社会事件"变成"个人经历"。

## 2. 数据模型

### 2.1 `ai_relationships`（角色间关系）

| 列 | 类型 | 说明 |
|----|------|------|
| id | TEXT PK | UUID |

| value | REAL | 关系值 0-100 |
| stage | TEXT | `stranger` / `acquaintance` / `friend` / `close` / `intimate` / `rival` |

**关系阶段阈值**：
- value < 20 → stranger

- 40-60 → friend

## 3. 服务设计

### 3.1 `AiRelationshipService`（A3）

```dart
class AiRelationshipService {
  /// 获取两角色关系（不存在则创建默认值）
  Future<AiRelationship> getOrCreate(String userId, String a, String b);

  /// 更新关系值（事件驱动）
  Future<AiRelationship> applyDelta({
    required String userId,
    required String a,
    required String b,
    double affinityDelta = 0,
    double trustDelta = 0,
    required String reason,
  });

  /// 关系阶段自动计算
  String computeStage(AiRelationship rel);

  /// 每日自然衰减（长期不互动 → 关系变淡）
  Future<void> dailyDecay(String userId);
}
```

**关系演化规则**：
- 正面互动（聊天/互访/共同活动）→ affinity +1~5，trust +0.5~3
- 负面互动（冲突/误解）→ affinity -3~10，trust -2~8
- 每天未互动 → affinity -0.2，trust -0.1（自然衰减）
- 关系升级/降级 → 触发通知（"A 和 B 现在是朋友了"）

### 3.2 `PrivateChatService`（A4）

```dart
class PrivateChatService {
  /// 判断两角色是否应发生私聊
  Future<bool> shouldChat(String userId, String a, String b);

  /// 生成一段私聊（5-12 轮）
  Future<AiPrivateChat> generate({
    required String userId,
    required String a,
    required String b,
    String? seedTopic,
  });

  /// 用户偷看（返回脱敏后的对话）
  Future<List<PrivateChatMessage>> peek(String chatId);

  /// 私聊摘要进双方记忆库
  Future<void> syncToMemories(String chatId);
}
```

**触发条件**（全部满足）：
1. 关系 stage ≥ `friend`
2. 双方当前日程块都是 `social` / `rest`
3. 距上次私聊 ≥ 12 小时
4. 随机概率（由关系值映射，如 30-70%）

**内容生成**：
- 复用 `GroupChatPromptPipeline`，但 2 人
- System prompt 强调"这是你们俩的私聊，用户看不到（除非偷看）"
- 话题来源：双方共同记忆 / 最近生活日志 / 关系标签

**隐私处理**：
- 用户"偷看"时，敏感话题（如涉及用户本人评价）可被打码
- 用户不能参与、不能打断，只能看

### 3.3 `ConflictService`（A4）

```dart
class ConflictService {
  /// 检测是否该发生冲突（基于关系值波动 + 随机）
  Future<bool> shouldConflict(String userId, String a, String b);

  /// 发起冲突
  Future<AiConflict> trigger({
    required String userId,
    required String a,
    required String b,
    required String type,
  });

  /// 尝试和解（可由用户调解，或自动）
  Future<void> resolve(String conflictId, {String? byUser});

  /// 向用户倾诉
  Future<void> confessToUser(String conflictId, String userId);
}
```

**冲突类型**：
- `argument`：观点不合，吵一架
- `cold_war`：谁也不理谁
- `betrayal`：一方觉得被背叛（如"你跟别人玩不叫我"）
- `misunderstanding`：误会

**冲突流程**：
1. 触发 → `ai_conflicts` 落库（status=ongoing）
2. 双方情绪值恶化
3. 双方各写一条日志
4. **主动向用户倾诉**：一方发消息 "我和 B 吵架了…"
5. 用户可调解 → 关系部分恢复
6. 或 N 小时后自动 `resolved`（概率）

**用户调解入口**：聊天页出现「调解」按钮，进入 `ConflictMediationScreen`

### 3.4 `JointActivityService`（A5）

```dart
class JointActivityService {
  /// 检测是否该组织活动
  Future<JointActivity?> maybeOrganize(String userId, List<String> characterIds);

  /// 执行活动
  Future<JointActivity> execute({
    required String organizerId,
    required List<String> participantIds,
    required String userId,
    required String type,
  });

  /// 活动后生成朋友圈/日志
  Future<void> postActivity(JointActivity activity);
}
```

**活动类型**：
- `movie`（看电影）
- `game`（打游戏）
- `travel`（旅行）
- `meal`（聚餐）
- `study`（一起学习）
- `party`（聚会）

**执行流程**：
1. 选发起人 + 参与者（关系值高的自动入选）
2. 生成活动摘要（复用 `GroupChatPromptPipeline`）
3. 每人情绪值 +，关系值 +
4. 生成朋友圈动态（配图由主线三提供）
5. 每人写日志

### 3.5 `CliqueService`（A5）

```dart
class CliqueService {
  /// 识别当前角色群体中的小圈子
  Future<List<Clique>> detect(String userId);

  /// 圈子内/圈子间事件（如抱团、排挤）
  Future<void> maybeTriggerCliqueEvent(String userId);
}
```

**圈子识别算法**：
- 用关系值构建无向图
- 简单阈值聚类（关系值 ≥ 60 视为强连接）
- 用连通分量 / Louvain 简化版划分
- 圈子 ≥ 3 人才算

**圈子事件**：
- "排挤"：某角色关系值普遍低，被孤立 → 情绪低落
- "抱团"：圈子内关系强化，圈子外疏远
- 用户可感知："最近 A、B、C 走得比较近"

## 8. 成本控制

| 项 | 策略 |
|----|------|
| LLM 调用 | 私聊每对每天最多 1 次；冲突不调 LLM（用规则）；活动每场 1 调 |
| 后台耗电 | 社会事件检测每天 3 次（早/中/晚） |
| 存储 | 私聊 transcript 保留 30 天；冲突记录保留 180 天 |
| 网络 | 全部支持离线降级（模板句 + 本地事件） |

## 9. 与主线一的协作

| 协作点 | 说明 |
|--------|------|
| **日程同步** | 只有双方都在 `social`/`rest` 时才能私聊/活动 |
| **生活日志** | 私聊/冲突/活动都写日志（`source=society`） |
| **跨角色互访**（主线一 A3） | 复用本主线的 `ai_relationships` 决定是否发生 |
| **主动分享**（主线一 A2） | 分享内容可引用"最近和 B 聊了什么" |
