# 20.0.0 主线三 · 多模态视觉（轻量）

> 上级文档：[`roadmap-20.0.0.md`](../roadmap-20.0.0.md)
> 迭代：A6（朋友圈配图 + AI 自拍 + 看图聊天）
> 数据库：v77
> 设计原则：**轻量、可选、可降级，不押重注**

---

## 1. 设计目标

让 AI 能"看见"和"被看见"，但**不引入角色一致性 LoRA、不做后台自动生图**：

| 场景 | 说明 | 触发方式 |
|------|------|----------|
| **朋友圈配图** | AI 发动态自动配图 | AI 自动（有生图配置时） |
| **AI 自拍** | 用户主动请求"发张自拍" | 用户手动 |
| **看图聊天** | 用户发图，AI 看图回复 | 用户手动 |

**核心约束**：
- prompt 中**不含任何用户隐私数据**
- 图片**本地存储**，不上传任何服务器
- **无 API Key 时全部按钮置灰**，不报错、不影响其他功能
- 默认关闭，用户在设置中显式开启

## 3. 服务设计

### 3.1 `ImageGenService`（抽象层）

```dart
/// 文生图提供方抽象接口
abstract class ImageGenProvider {
  String get id;
  String get displayName;
  bool get requiresApiKey;

  /// 生成图片，返回本地文件路径
  Future<ImageGenResult> generate(ImageGenRequest req);

  /// 健康检查
  Future<bool> ping();
}

class ImageGenRequest {
  final String prompt;
  final String? negativePrompt;
  final int width;
  final int height;
  final int? seed;
  final String? referenceImagePath; // 可选，图生图
}

class ImageGenResult {
  final bool success;
  final String? filePath;
  final String? error;
  final int? seed;
}

/// 统一入口
class ImageGenService {
  static final ImageGenService instance = ImageGenService._();
  ImageGenService._();

  /// 注册 provider
  void register(ImageGenProvider p);
  void setActive(String providerId);

  /// 生成并落库
  Future<AiGeneratedImage> generate({
    required String userId,
    required String characterId,
    required String kind,
    required String prompt,
  });
}
```

**内置 Provider**：
| Provider | 说明 | 是否需要 Key |
|----------|------|:---:|
| `mock` | 本地占位图（纯色 + 文字），永远可用 | 否 |
| `tongyi` | 通义万相 HTTP API | 是 |
| `jimeng` | 即梦 HTTP API | 是 |
| `custom` | 用户自定义 OpenAI 兼容端点 | 是 |

> **重要**：默认只用 `mock`，其他 provider 需用户在设置中显式开启 + 填 Key。

### 3.2 `SelfieService`

```dart
class SelfieService {
  /// 用户主动请求自拍
  Future<AiGeneratedImage> request({
    required String userId,
    required String characterId,
    String? sceneHint, // "在海边" / "刚睡醒"
  });
}
```

**Prompt 构造模板**：
```
A portrait photo of {characterName}, {appearanceDescription},
{sceneHint}, {styleKeyword},
shot on smartphone, selfie angle, natural lighting,
high quality, detailed
```

**禁止项**：
- 不注入用户 ID / 用户名 / 任何用户数据
- 不注入聊天记录
- 只使用角色的**公开人设字段**（name / appearance / personality）

### 3.3 `MomentImageService`

```dart
class MomentImageService {
  /// 为朋友圈动态生成配图
  Future<AiGeneratedImage?> generateForMoment({
    required String userId,
    required String characterId,
    required String momentContent,
  });
}
```

**触发策略**：
- 仅在 AI 主动发动态时触发（用户自己发的动态不自动配图）
- 每天最多 3 张（避免成本失控）
- 用户可在设置中关闭

**Prompt 构造**：
- 从动态正文抽取场景关键词
- 用角色风格修饰（"她的视角" / "她的风格"）

### 3.4 `VisionChatService`（看图聊天）

```dart
class VisionChatService {
  /// 用户发图 + 文字，AI 看图回复
  Future<String> chatWithImage({
    required String userId,
    required String characterId,
    required String imagePath,
    String? userText,
  });
}
```

**实现方式**：
- 若当前 LLM 支持多模态（如 GPT-4o / Claude / Gemini）→ 直接把图转 base64 发过去
- 若不支持 → 降级提示"当前模型不支持看图"

**UI 入口**：
- 聊天输入框新增「图片」按钮
- 用户可选"发给 AI 看"或"仅保存本地"

## 4. 存储与隐私

### 4.1 文件存储

- 路径：`{docs}/solace/images/{userId}/{characterId}/{id}.png`
- 与"备份导出"打通：导出时图片一起打包
- 清理策略：删除动态时，关联图片可级联删除（可配置）

### 4.2 隐私保护

| 措施 | 说明 |
|------|------|
| prompt 不含用户数据 | 只用角色公开人设字段 |
| 图片本地存储 | 生成后立即下载到本地，不依赖远程 URL |
| 不上传聊天记录 | 看图聊天时只上传用户主动选的图 + 当轮文字 |
| 默认关闭 | 需用户显式开启并填 Key |
| 可随时删除 | 设置页有"清空所有生成图片"按钮 |

## 9. 成本控制

| 项 | 策略 |
|----|------|
| 生图次数 | 每角色每天 ≤ 3 张（可配） |
| 生图质量 | 默认 512x512；用户可调 |
| 生图触发 | 只在用户主动 / AI 主动发动态时 |
| 多模态 LLM | 只在用户发图时调用 |
| 网络 | 无网络时全部降级为 mock / 提示 |

## 10. 明确不做的

以下**明确不做**（避免过度工程）：

- ❌ 角色一致性 LoRA / IP-Adapter
- ❌ 图生视频 / 数字人
- ❌ 实时视频通话
- ❌ 云端图片托管
- ❌ 后台自动批量生图
- ❌ 多角色合影（除非后续有明确需求）

> 如果未来要做角色一致性，作为 21.0.0 的独立主线。
