隐私政策

最后更新：2026 年 8 月 20 日

本地优先承诺

Solace 是一款本地优先的 AI 陪伴应用。聊天内容、角色配置、记忆、设置和 API 密钥默认保存在你的设备上。Operit Agent 只在你明确使用相关能力时访问设备工具或绑定的工作区。

我们不收集什么

  • 聊天内容、角色设定和记忆内容
  • API 密钥、认证信息和设备标识符
  • 位置、联系人、照片或其他个人文件
  • 广告标识、行为画像和第三方分析数据

第三方 AI 服务

当你发送消息时，应用会根据你的配置直接调用对应 AI 服务商。该服务商可能按照其自己的隐私政策处理请求。Solace 不代理、不保存这些请求。

Operit 与工作区

设备操作、Shell 命令和工作区文件访问属于不同能力链路。工作区工具只应处理你明确绑定的目录；写入、编辑、回滚和命令执行由应用权限策略控制。恢复默认目录只解除绑定，不删除原目录。

数据安全与备份

请使用系统锁屏并妥善保存本地备份文件。卸载应用或清除应用数据可能删除本地内容，建议在重要操作前导出备份。

联系我们

如果你对隐私有疑问，请通过应用内反馈渠道联系开发者。
