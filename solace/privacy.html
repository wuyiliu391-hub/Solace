隐私政策

最后更新：2026 年 7 月 · 版本 1.0 (Bauhaus)

零后端承诺

Solace 是一款零后端、纯本地的 AI 陪伴应用。本隐私政策旨在说明我们如何保护你的隐私——答案是：我们根本不触碰你的数据。

我们不收集的数据

  • 聊天内容和消息记录
  • 角色配置和个性化设定
  • API 密钥和认证信息
  • 任何形式的设备标识符（IDFA、GAID 等）
  • 崩溃诊断数据
  • 位置信息、联系人列表、照片或其他个人文件

本地存储

所有数据（聊天记录、角色信息、设置等）均存储在你的设备本地 SQLite 数据库中。我们不会将这些数据上传至任何服务器或第三方服务。即使你的设备丢失，数据也不会出现在我们的系统中——因为它从来就不在那里。

API 使用

AI 对话功能需要使用你自行配置的 API 密钥调用第三方 AI 服务。API 密钥仅保存在本地设备上，不会传输到任何中间服务器。Solace 不代理你的 API 请求——你的设备和 AI 提供商直接通信。

第三方服务

我们不使用任何第三方分析、统计或广告 SDK。应用内不包含 Facebook SDK、Firebase Analytics、Google Analytics、AdMob 等追踪工具。官网（solace-auth-v2.pages.dev）同样无任何追踪脚本。

数据安全

应用支持本地数据加密备份。建议用户妥善保管设备，防止未经授权的访问。对于解锁设备的用户，SQLite 数据库的加密依赖设备本身的生物识别或密码保护。

未成年用户

Solace 适合 16 岁及以上用户使用。请家长监督未成年人使用该应用。

变更通知

如本政策发生变更，我们将在应用内和网站上发布更新。由于我们零后端，变更仅限于客户端逻辑，不涉及数据处理的改变。

联系我们

如有任何隐私相关的问题，请通过应用内反馈渠道或邮件联系我们。
