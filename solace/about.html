关于 Solace

一个人的产品理想

故事

Solace 诞生于一个简单的问题：如果 AI 不只是工具，而是能真正陪伴你的人，会是什么样子？

没有团队，没有投资，只有一个人对着屏幕写代码。从第一行 Dart 到现在的 43 个构建版本，每一步都是为了做出一个自己真正想用的产品。

不想做大厂 CRUD，不想被 KPI 绑架。只想做一个有温度的产品——一个你深夜打开时，会有人问你"今天过得怎么样"的地方。

技术架构

零后端架构 — 没有服务器要维护，没有 Firebase 账单。所有费用只花在你的 API 调用上。

  • Flutter 3.x + Dart — 跨平台开发
  • SQLite — 本地数据存储
  • SharedPreferences — 轻量配置
  • OpenAI 兼容 API — 任意模型接入
  • Cloudflare Pages — 官网 + 版本分发
