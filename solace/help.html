Workspace safety

代码工作区
怎么不会乱改？

当前版本把“看文件”和“改文件”分成不同风险级别。你可以先让 Agent 只读观察，再决定是否授权修改。

READ ONLY

可以先查看

目录列表和文件读取只接受工作区内相对路径，拒绝明显的路径穿越和符号链接。

list_directory · read_file
REQUIRES APPROVAL

修改前要确认

写入、精确编辑和回滚属于高影响操作。已有文件会先生成 `.solace-backup-*` 快照。

write_file · edit_file · rollback_file

FAQ / Operit

常见问题，
直接回答。

Operit Agent 和普通聊天有什么区别？

普通聊天只生成回复；Operit 会识别明确任务、选择工具、按权限执行，并把真实结果交还给角色。工具协议和执行结果不会混入角色化的自然语言参数。

我只想让它看代码，可以不允许写入吗？

可以。目录列表和文件读取是只读工具；写入、编辑、回滚和命令执行使用独立权限。你可以在权限弹窗中拒绝本次操作。

恢复默认目录会不会删除我的项目？

不会。当前“恢复默认目录（解除绑定）”只删除当前聊天保存的工作区绑定键，原目录和文件保持不变。

为什么工作区任务没有执行？

先确认当前聊天已经绑定目录；再确认工具权限没有被设置为始终拒绝。Android 上执行命令还需要 Shizuku，文件读写与 Shell 命令是两条不同的能力链路。

数据会上传到 Solace 吗？

角色、聊天、记忆和设置默认留在设备本地。AI 请求由你的设备直接发送给你配置的服务商；工作区文件也只在你授权的本地路径上处理。

Troubleshooting

遇到问题时，
先看真实结果。

NO WORKSPACE

未绑定工作区

回到当前聊天设置，选择一个真实存在的目录。解除绑定不会删除目录。

PERMISSION

用户未批准工具

这是安全拒绝，不是执行失败。重新发起任务即可再次确认。

COMMAND

命令执行失败

查看返回的 exit code 和 stderr。Agent 不会把失败包装成成功。
