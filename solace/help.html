快速开始

如何配置 API Key？

推荐使用 SiliconFlow（国内可用，新用户有免费额度）：

  1. 注册 SiliconFlow 账号
  2. 在控制台创建 API Key
  3. 打开 Solace → 设置 → API 配置
  4. 填入 API 地址和密钥

如何创建角色？

在「角色」页面点击右上角 + 号，可以：

  • 手动创建：填写角色名称、性格、背景故事
  • 从回忆创建：上传聊天记录和照片，AI 自动分析性格

常见问题

为什么 AI 不回复？

检查以下几点：

  • API Key 是否正确配置
  • 网络连接是否正常
  • API 额度是否用完
  • 尝试切换备用模型
数据会丢失吗？

所有数据存储在本地 SQLite 数据库中。建议定期备份：

  • 设置 → 数据管理 → 导出备份
  • 备份文件保存在手机存储中
支持哪些 API 提供商？

Solace 支持任何 OpenAI 兼容的 API 接口。包括：

  • SiliconFlow (推荐国内使用)
  • OpenAI API
  • Anthropic Claude
  • Google Gemini
  • 本地 Ollama 模型

隐私说明

零后端架构： Solace 没有服务器，所有数据完全存储在你的设备上。聊天记录、角色设定、亲密关系、记忆内容——全部保存在本地 SQLite 数据库中。

无追踪： 应用不会收集任何用户数据，不会上传任何个人信息，没有任何第三方跟踪脚本。

开源透明： 代码可审查，逻辑透明。你可以自行构建 APK，验证每一个字节。
