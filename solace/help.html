快速上手

打开 Solace，第一件事做什么。

从零开始，只需要这三步。

01

配置模型服务

打开应用 → 设置 → AI 配置，填写 OpenAI 兼容接口的地址、密钥与模型名称。Solace 不代理你的请求，数据只在你和服务商之间往来。

02

创建第一个角色

从内置角色开始，或动手创造一个。先通过普通对话确认关系基调，再慢慢探索她的记忆、情绪和更多能力。

03

探索高级功能

熟悉聊天后，可以试试语音通话、人生模拟、朋友圈和群聊。这些功能都是可选的，按你喜欢的节奏来就好。

AI 模型配置

选一个你信任的模型。

Solace 支持所有 OpenAI 兼容接口的模型服务商，并提供内置模型一键切换。

支持的模型类型

任何兼容 OpenAI API 格式的模型均可使用：GPT 系列、Claude（通过兼容接口）、DeepSeek、GLM 系列、Qwen 系列等。只需填写正确的 API Base URL 和 API Key。

内置模型（一键切换）

Solace 内置了 NVIDIA Step-3.7-Flash 和 SiliconFlow GLM-Z1-9B 等模型入口。在设置页选择即可，无需手动填写地址，但需要配置对应的 API Key。

API Key 安全吗？

API Key 保存在设备本地 SQLite 数据库中，Solace 不会将密钥上传到任何服务器。你的 AI 请求直接发送给你配置的服务商，不经过 Solace 代理。

为什么模型不回复 / 回复很慢？

先确认 API Base URL 和 Key 填写正确。如果服务商在大陆访问受限，可能需要配置网络代理。流式模式下，慢回复通常与服务商响应速度有关，Solace 内部已设置 90 秒超时保护。

常见问题 · FAQ

你可能会问的。

收集了用户反馈中最常见的问题，答案直接放在这里。

Solace 会收集我的数据吗？

不会。所有聊天、角色、记忆和设置保存在设备本地 SQLite 数据库中。Solace 没有云端服务器接收你的数据。AI 请求由你的设备直接发送给你配置的模型服务商。

需要注册账号才能使用吗？

不需要。Solace 没有账号系统，安装后直接使用。所有数据在本地，卸载或清除数据会丢失，建议在重要操作前导出备份。

如何备份和恢复数据？

在设置页面可以一键导出备份文件（.db 格式），将文件保存到安全位置。恢复时选择「导入备份」，选择对应文件即可。备份文件包含所有角色、聊天记录和记忆。

角色会忘记之前的事吗？

会，但这是设计而非缺陷。Solace 采用艾宾浩斯遗忘曲线：重要的事会被反复巩固，琐碎的细节会自然淡出。你可以通过重新提及来刷新记忆，就像对真人一样。

语音通话是怎么工作的？

点击角色卡片上的通话按钮：你说的话通过本地 VAD 自动断句 → 本地 STT 转写成文字 → AI 生成回复 → 用角色的克隆音色逐句朗读。全程半双工防回声，不会你说一句它打断一句。

Operit Agent 是什么？必须用吗？

Operit Agent 是 Solace 的可选进阶功能，让角色在明确授权下执行设备操作和代码工作区任务。如果你不需要，完全不用开启，不影响普通聊天和陪伴体验。

Solace 有 iOS 或桌面版吗？

目前 Solace 专注于 Android 平台。未来是否扩展取决于用户需求与开发资源。关注本站可获取最新发布信息。

如何反馈问题或建议？

建议通过应用内反馈渠道、GitHub Issues 或应用商店评论区提交。你的每一条反馈都会影响 Solace 接下来的方向。
