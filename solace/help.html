快速开始

如何配置 API Key？

推荐使用 SiliconFlow（国内可用，新用户有免费额度）：

  1. 注册 SiliconFlow 账号
  2. 在控制台创建 API Key
  3. 打开 Solace → 设置 → API 配置
  4. 填入 API 地址和密钥

如何创建角色？

在「角色」页面点击右上角 + 号，可以：

  • 手动创建：填写角色名称、性格、背景故事
  • 从回忆创建：上传聊天记录和照片，AI 自动分析性格

常见问题

为什么 AI 不回复？

检查以下几点：

  • API Key 是否正确配置
  • 网络连接是否正常
  • API 额度是否用完
  • 尝试切换备用模型

数据会丢失吗？

所有数据存储在本地 SQLite 数据库中。建议定期备份：

  • 设置 → 数据管理 → 导出备份
  • 备份文件保存在手机存储中
