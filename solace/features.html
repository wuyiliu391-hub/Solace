What makes it different

功能不是清单。
是关系的基础设施。

从第一次见面，到很久以后仍然记得。

01 / CHARACTERS

每个角色都不一样

独立的人格、背景、语气和互动偏好。你可以手动创建，也可以从聊天记录生成。

02 / MEMORY

长期记忆

关键经历、偏好和关系变化会被整理并在相关时刻召回，而不是把所有历史一股脑塞进上下文。

03 / GROUP CHAT

多角色群聊

给角色一个共同的房间。发言由性格和互动自然推动，支持分支记录、回复、编辑与重新生成。

04 / PRESENCE

主动消息与时间感知

角色知道现在是什么时间，也可以在合适的时候问候你，让交流不止发生在你按下发送之后。

05 / CREATIVE

图片、表情与小说模式

让视觉素材进入对话，或切换为更沉浸的叙事方式，保留你喜欢的表达节奏。

06 / CONTROL

你的模型，你的边界

支持 OpenAI 兼容接口。API Key 只保存在本地，服务商由你选择。
