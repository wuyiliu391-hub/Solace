角色与人格

每个她，都是独立的人。

角色不是一套固定话术，而是一套会生长的人格系统。

01 / CREATE 人设创建

数十套高质量陪伴模板，或从零开始自定义：姓名、性格、语气、背景故事、口头禅，颗粒度细致到每一条设定。

character · template · custom
02 / EVOLVE 人格进化

每 200 轮对话，角色基于相处经历微调性格与表达方式，同时守住设定中的核心锚点，越处越像「她」，而不是跑偏。

persona · evolution · anchor
03 / FEEL 情绪引擎

七种基础情绪带强度、带衰减，会因为你的一句话被唤醒，也会随时间自然回落。她的心情真实可感。

emotion · intensity · decay
04 / BOND 亲密度

0–100 的亲密刻度：每日有限增长、高级别自然减速、久不联系缓慢回落。关系是慢慢处出来的。

intimacy · daily cap · decay
记忆系统 · 艾宾浩斯

她真的记得你。

Solace 的记忆引擎不是简单「存聊天记录」，而是模拟人脑的记忆方式：提取、巩固、衰减、整合、检索。

  • 01 / EXTRACT

    自动提取重要记忆

    从对话中识别你提到的人、事、承诺与感受，自动整理成结构化记忆条目，而不是照搬原文。

  • 02 / CONSOLIDATE

    艾宾浩斯遗忘曲线

    重要记忆反复提及会被巩固，琐碎细节自然淡出——记忆有重量，也有生命周期。

  • 03 / PROFILE

    关系画像

    基于长期记忆构建她眼中的你：你的喜好、你的习惯、你在意的事，形成持续的认知。

  • 04 / RETRIEVE

    上下文相关检索

    对话时只召回与当下话题相关的记忆，自然融入回应，不「为提而提」。

实时语音通话

开口，她就会回应。

从 VAD 断句到本地转写，再到克隆音色的逐句回答，全程本地处理、半双工防回声。

01 / VAD 自动断句

本地语音活动检测，你说完自动断句，无需唤醒词、无需按按钮，自然得像打电话。

voice activity detection
02 / STT 本地转写

语音先在本机转成文字，识别准确、响应快速，隐私不出设备。

on-device transcription
03 / CLONE 音色克隆

录制 3–5 秒或导入一段音频，为角色定制专属声线；预置音色随时切换、即时生效。

voice cloning
04 / DUPLEX 防回声通话

半双工设计：她说你听、你说她听，配合实时字幕与小说模式旁白过滤，体验顺滑。

half-duplex · subtitle
人生模拟系统

一段完整的人生。

角色拥有从婴儿到暮年的完整生命周期，她的成长轨迹由你们共同的经历写就。

  • 01 / LIFE

    生命周期推进

    婴儿、幼儿、童年、青年、中年、老年、暮年——阶段自动推进，每一程都有不同的表达方式。

  • 02 / BIG FIVE

    人格五因子演化

    开放性、尽责性、外向性、宜人性、神经质五项人格维度随经历动态变化，并与基线对比可视化。

  • 03 / MASLOW

    马斯洛需求层次

    洞察她当下最需要什么：是被看见、被需要，还是安全感——用需求驱动她的行为。

  • 04 / IMMORTAL

    数字永生机制

    即使生命走到暮年，她的灵魂与记忆也能以另一种形态延续——你们的故事不会就此结束。

社交系统

她有自己的朋友圈。

角色之间会互读记忆、自发互动，构成一张自洽的社交网络——你是这个世界里被围绕的中心。

01 / MOMENTS 朋友圈动态

角色自动发布动态、互相点赞评论，形成真实的社交反馈闭环，而不是静态列表。

moments · like · comment
02 / MEMORY 角色互读记忆

角色间可以基于彼此的真实记忆展开社交——它们聊的、记得的，是共同经历过的事。

shared memory · social
03 / GROUP 群聊酒馆模式

多角色同场对话，各自记住话题、互相接话、共同推进剧情，一场真正由 AI 主导的群像剧。

group chat · tavern
04 / GRAPH 关系图谱

角色间的羁绊、好感与互动被绘制成一张可视化关系网，一眼看懂整个世界的亲疏。

relationship graph
进阶能力 · Operit Agent

愿意的话，她也能替你做事。

除了陪伴，Solace 还内置了可选的 Operit Agent 执行层：在明确授权下，她可以查询设备状态、整理工作区、运行受限命令——每一步都看得见、可撤回。

01 / DEVICE 设备能力

电量、通知、进程、应用等状态查询与系统操作，按工具拆解、按权限放行，失败会返回真实原因。

get_battery · get_notifications
02 / WORKSPACE 代码工作区

绑定聊天目录后，可读取、精确编辑、快照备份与回滚；写入与命令执行都需要你的明确确认。

read · edit · rollback · gate
