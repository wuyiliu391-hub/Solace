One agent, three surfaces

从对话，
走到行动。

Operit 不把工具调用藏在黑箱里。每一次任务都经过意图、工具、权限和真实结果，角色只负责把它说得像一次自然的共同经历。

01 / COMPANION

先理解你要什么

自然语言进入统一意图层。闲聊不会误触设备操作，明确任务才会进入 Agent Loop。

conversation → intent
02 / DEVICE

再调用真正的能力

电量、通知、应用、进程、截图和系统操作各有工具，失败会返回真实原因，不伪装成功。

tool → execution → result
03 / WORKSPACE

也能一起写代码

绑定当前聊天的工作区后，Agent 可以列目录、读取、精确编辑、备份回滚，并运行受限命令。

read · write · edit · rollback
